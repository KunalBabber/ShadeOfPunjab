Build a premium, modern, production-ready clothing e-commerce website for **“Shades of Punjab”**, a clothing retail brand with two physical store locations in **Jamshedpur, Jharkhand, India**.

Use the brand's Instagram presence as a visual/content reference:
Instagram: https://www.instagram.com/shades.of.punjab.amritsar/

Important:

* Do not invent products, prices, addresses, phone numbers, reviews, offers, or business claims.
* Where information is unavailable, create editable placeholders that can be managed from the admin panel.
* The website should be designed so the business owner can replace all placeholder content with actual brand information.
* The two physical store locations must be represented separately.
* The website should feel like a real premium Indian fashion brand, not a generic template.

## 1. Overall Brand Direction

Create a sophisticated Indian fashion aesthetic combining:

* Punjabi cultural identity
* Modern Indian fashion
* Premium retail-store presentation
* Elegant typography
* High-quality fashion photography
* Clean layouts
* Subtle Punjabi-inspired visual details
* Strong mobile-first experience

Avoid excessive traditional decoration. The design should feel contemporary, premium and commercially usable.

Suggested visual direction:

* Warm ivory / off-white backgrounds
* Deep navy or charcoal typography
* Rich burgundy / wine accents
* Subtle gold accents
* Soft beige sections
* Large editorial fashion imagery
* Generous whitespace
* Elegant serif headings + modern sans-serif body text

Do not make the website overly colorful.

## 2. Technology Stack

Build using:

* Next.js 15+
* TypeScript
* App Router
* Tailwind CSS
* shadcn/ui where appropriate
* MongoDB
* Mongoose or an equivalent clean database layer

* Secure authentication

* SEO-friendly architecture
* Image optimization
* Server-side rendering where beneficial

Structure the project cleanly so it can later be deployed to Vercel or another production platform.
